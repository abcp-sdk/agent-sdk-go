# agent-sdk-go

Go SDK for the abc agent (`agent.v1.AgentService` + `agent.v1.AdminService`).
**Generated code only.** The typed messages and Connect clients are produced by
`buf` from `agent/v1/agent.proto` (see `abcp-sdk/agent-proto`):

```
agent/v1/agent.pb.go                     # protoc-gen-go
agent/v1/agentv1connect/agent.connect.go # protoc-gen-connect-go
```

Per the connectrpc convention the caller owns the transport: build an
`http.Client` (the agent serves HTTP/2) and hand it — with a bearer
interceptor — to the generated client constructor.

```go
import (
	"context"
	"net/http"

	"connectrpc.com/connect"
	agentv1 "github.com/abcp-sdk/agent-sdk-go/agent/v1"
	"github.com/abcp-sdk/agent-sdk-go/agent/v1/agentv1connect"
)

client := agentv1connect.NewAgentServiceClient(
	http.DefaultClient, "https://agent.example.com",
	connect.WithInterceptors(authInterceptor(token)),
)
sessions, err := client.ListSessions(ctx, connect.NewRequest(&agentv1.ListSessionsRequest{}))
```

The agent serves HTTP/2 only; build an HTTP/2 (h2c / ALPN h2) `http.Client` on
the wire, as the tests demonstrate.

## Regenerate

Generated by `abcp-sdk/agent-proto` (source of truth) and distributed here by
`agent-proto/scripts/sync-agent-sdks.sh`. **Do not edit `agent/v1` by hand.**

```bash
(cd ../agent-proto && ./scripts/sync-agent-sdks.sh --only go)
go test ./...
```
